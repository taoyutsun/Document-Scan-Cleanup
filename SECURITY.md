# 回報問題 / Reporting issues

請先使用自己製作的合成文件重現問題，再至 [Issues](https://github.com/taoyutsun/Document-Scan-Cleanup/issues) 回報。請勿附上真實客戶資料、私人文件、未整理的變更報告、存取憑證或完整本機路徑。

清理結果須由使用者檢查；這個工具不保證自動找出所有敏感資訊。正式標籤、簽章、保護與存取控制不屬於要移除的內容。

Use synthetic reproductions in [Issues](https://github.com/taoyutsun/Document-Scan-Cleanup/issues). Do not include real client data, private files, unedited reports, credentials or full local paths. Review output copies; the tool does not guarantee detection of all sensitive information or remove access controls.
